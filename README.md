# 🎓 StudyMate AI

> AI-Powered GTU BCA Study Assistant

StudyMate AI is a modern AI-powered study assistant designed for GTU BCA students. It helps students prepare for exams, practice MCQs, understand topics, manage notes, and study more effectively using Gemini AI.

## ✨ Features

- 🤖 AI-powered study assistance
- 📝 Exam-oriented answers
- 🎯 Multiple answer formats: 2, 3, 5, 7, 10 and 15 marks
- 🧠 AI-generated MCQ Quiz
- 📚 GTU BCA Semester 1–6 curriculum support
- 📖 Subject → Unit → Topic navigation
- 📄 Notes upload and study support
- 📅 Study planning
- 💾 Save important study content
- 🔍 Search subjects and topics
- 🌐 Hindi / English support
- 🌙 Light / Dark mode
- 🔊 Global sound controls
- 📱 Responsive mobile-first design
- ⚡ AI loading and error handling

## 🛠️ Technologies Used

## 🤖 AI Integration

StudyMate AI uses Google's Gemini AI to provide:

- Topic explanations
- Exam-oriented answers
- Marks-based answer generation
- MCQ generation
- Study assistance

The application also handles loading states, API errors, network issues and quota limitations gracefully.
